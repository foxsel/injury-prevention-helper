# 부상 예방·회복 운동 도우미

축구·농구·배구·야구·헬스를 하는 사람이 **발목·무릎·어깨**의 부상을 예방하거나 회복할 때, 종목과 통증 상태에 맞는 운동을 한곳에서 안내하는 웹앱입니다. **전문가 검토 전 시제품**이며 의료 행위를 대신하지 않습니다.

## 하는 일

- **맞춤 운동 추천**: 사용 유형(예방형/회복형), 종목, 부위, 부위별 통증(0~10점)을 입력하면 미리 정리한 운동 목록에서 최대 5개를 추천합니다. 종목별로 부담이 많이 가는 부위에는 '추천' 표시가 붙습니다.
- **운동 가이드**: 방법(3~5단계), 횟수·세트, 주의사항, 중단 기준을 보여 줍니다.
- **진행 기록**: 운동 전·후 통증을 기록하면 운동·부위별 그래프와 분석을 보여 줍니다. 기록은 이 브라우저에만 저장되고 서버로 보내지 않습니다.

## 안전 규칙 (요약)

- 한 부위라도 통증 6점 이상이거나 체중을 싣기 어려우면 추천하지 않고 병원 상담을 안내합니다.
- 통증 3점 이상이면 점프 같은 고충격 운동은 후보에서 뺍니다.
- AI는 운동 번호만 고르고, 화면의 운동 문장은 모두 `lib/exercises/data.ts`의 목록에서만 나옵니다.
- 진단·처방·효과 보장 표현을 쓰지 않습니다. 입력값은 서버에 저장하지 않습니다.

> ⚠ 안전 기준 숫자는 임의로 정한 값이고, 어깨 예방 운동 4개는 근거 없는 **가상 샘플**입니다. 실제 공개 전에 근거 확인과 전문가 검토가 필요합니다. 아래 "공개 전 남은 과제"를 보세요.

## 공개 전 남은 과제

- **AI 호출 횟수 제한**: 누구나 로그인 없이 추천 API를 부를 수 있어 OpenAI 요금이 쌓일 수 있습니다. 코드가 아니라 설정으로 막습니다. ① OpenAI에서 이 앱 전용 키를 만들고 월 사용 한도를 작게 설정 ② Vercel Firewall에서 `/api/recommend`에 IP당 횟수 제한(예: 1분 10회) ③ Preview 배포에는 키를 넣지 않거나 배포 보호를 켬. (키는 Vercel 환경변수에만 등록하고 `.env`는 올리지 않습니다.)
- **어깨 예방 운동 교체**: 지금 4개는 근거 없는 가상 샘플입니다. 출처가 있는 운동(예: OSTRC 어깨 부상 예방 프로그램, Andersson 등, Br J Sports Med 2017;51:1073)으로 바꿔야 합니다.
- **전문가 검토와 출처 확인**: 통증 6점·3점, 5개 같은 안전 기준 숫자는 임의 값입니다. 운동 출처(AAFP 발목 염좌 안내, FIFA 11+, 분당서울대병원 환자교육)는 AI 도구로 요약했으니 원문과 대조하고 FIFA 11+ 서지 정보를 채워야 합니다. 종목별 주요 부위 표도 일반 정보 수준입니다.
- **개인정보 안내**: 입력값이 OpenAI로 전송되므로 공개할 때 개인정보 처리 안내를 법적 기준에 맞게 보완해야 합니다. 손 그림 파일(`public/hands.webp`)의 이용 권한도 확인하세요.

## 실행 방법

Node.js가 설치되어 있어야 합니다.

```bash
npm install
npm run dev     # http://localhost:3000
```

AI 추천을 쓰려면 프로젝트 폴더에 `.env` 파일을 만들고 `OPENAI_API_KEY`를 적습니다. (이 파일은 git에 올라가지 않으며, 키를 문서나 채팅에 적지 마세요.) 모델은 기본 `gpt-4.1-mini`이고 `OPENAI_MODEL`로 바꿀 수 있습니다.

| 명령 | 하는 일 |
|------|---------|
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 자동 시험 실행 (Vitest) |
| `npm run lint` | 코드 검사 |
| `npm run build` | 배포용 빌드 |
